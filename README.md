# 舞台吊挂演出放行台

这是面向剧场技术团队的吊挂方案安全治理应用。技术总监可建立或复制制作档案，原子调整吊挂元素并批量调度动作提示；系统执行可重复的载荷、路径、净空、人员禁入和时序分析，并保留可对比的历史分析批次；操作员按当前分析修订记录不可变排练证据；独立安全复核员通过退回意见回应清单完成逐项复核和冻结；技术总监最终签发、作废或从同一冻结清单换发限定演出场次的放行凭据。

应用由 Go 服务直接提供响应式浏览器工作台和同源 JSON API，无需 Node 构建链。数据保存在本地 SQLite 文件中，所有变更使用 `expectedRevision` 防止并发覆盖，并用 `idempotencyKey` 固化首次命令结果。附件不上传二进制内容，只登记文件名与 SHA-256 摘要。

## 构建

```text
go build ./cmd/stageclearance
```

## 运行

```text
go run ./cmd/stageclearance -addr=127.0.0.1:19081
```

默认监听 `127.0.0.1:19081`。未显式设置 `-addr` 时，也可通过 `PORT` 指定端口，服务将监听 `127.0.0.1:<PORT>`。为避免意外暴露，服务拒绝非回环监听地址。默认数据库文件为 `stageclearance.db`，可用 `-db` 指定其他路径。

浏览器访问 `http://127.0.0.1:19081/` 即可完成复制建档、批量方案编排、分析对比、阻断整改闭环、排练覆盖、复核回应和凭据全生命周期操作；左侧的校验区会区分有效、已作废和已换发凭据，并复核冻结内容是否匹配。

## 测试与自检

```text
go test ./...
```

真实 HTTP 有界自检会使用临时 SQLite 数据库，启动回环监听，经公开 API 完成整条放行流程，然后自行关闭：

```text
go run ./cmd/stageclearance -selfcheck -addr=127.0.0.1:19081
```

自检数据目录在结束时自动清理，不会写入生产数据库。
